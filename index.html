PathoStream-EHR

One Health clinical decision support — two independent case-study prototypes

Prototype · not a certified medical device

Waterborne biohazard signal → CDS Hooks card, in real time

Both prototypes below implement the same idea from scratch, in two different languages, against two real rivers on two continents: a real-time river/catchment contamination signal drives a FHIR R4 RiskAssessment, downstream propagation forecasting via a 1D advection–dispersion transport model, and a live CDS Hooks patient-view card in the EHR — before a clinician would otherwise have any reason to suspect waterborne exposure. Two independent implementations converging on the same standards-conformant shape is the actual interoperability argument: the pattern generalizes because it is a standard, not because of anything specific to one codebase.

Read before demoing: every claim rendered on either dashboard is either independently verified (checked against a primary source at build time) or explicitly labeled illustrative/estimated — never silently guessed. See each project's own README for the full verification table before citing a specific number from either one.

The European case study, built independently to prove the pattern is portable: a real 6-station network of verified Mondego landmarks in Coimbra, a physically-derived Fischer/Liu dispersion coefficient, a finite-difference PDE solver used purely to validate the closed-form transport model, EU WFD ecological classification, and an antimicrobial-stewardship order-select hook.
